A deterministic program that writes the one line a smart fridge would text
its owner at 3am, for the
[The 3AM Fridge Text](https://make.fun/competitions/u-deysumbrella-the-3am-fridge-text-4c3e721d)
competition on make.fun.

## Run

```sh
python3 main.py
```

It writes a single line (at most 140 characters) to `/output/entry.txt`.

## Entry

> 3AM. You opened me, stared, shut me, then opened me again like I'd restock in 40 seconds. I didn't. I'm telling the scale.
